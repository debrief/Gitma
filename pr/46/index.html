TMA via ML

Can a neural network learn target motion analysis from bearings alone?

This is a proof of concept, not a product. A neural network is trained on large volumes of simulated bearings-only data, and asked to estimate a target's range, course and speed. Each iteration ends at a gate; a failed early gate ends the project with a short write-up.
