Results: iteration 1 (G1)

Question: is there a learnable signal? G1 passes if both the instantaneous and time-late models' median range error, 5 minutes after the zig, is below half of the naive baseline's. The models page describes the four architectures; the evaluation page defines the metrics.

With the experiment's paired bootstrap (2,000 resamples of the test scenarios), each G1 check passes only if the whole 95% interval of model/naive is below 0.5, fails if it is wholly above, and is otherwise inconclusive.

Additional checks, recorded in the verdict:

  • time-late-not-worse: the time-late model is never more than 5% worse than the instantaneous one at any point on the curve (it sees strictly more data).
  • *-beats-control: each recurrent model beats its control (causal CNN, MLP) at 5 minutes after the zig and at the end of the window.
  • shuffled-labels-at-naive: a model trained on shuffled labels scores within ±10% of naive.

All numbers below are from the committed experiment folder, generated at site build time.
