# Results: iteration 1 (G1)

**Question:** is there a learnable signal? G1 passes if both the
[instantaneous](../glossary.md) and [time-late](../glossary.md) models' median range error,
5 minutes after the zig, is below half of the [naive baseline](../algorithms/naive-baseline.md)'s.
The [models](../algorithms/models.md) page describes the four architectures; the
[evaluation](../evaluation.md) page defines the metrics.

With the experiment's paired bootstrap (2,000 resamples of the test scenarios), each G1 check
passes only if the whole 95% interval of model/naive is below 0.5, fails if it is wholly above,
and is otherwise **inconclusive**.

Additional checks, recorded in the verdict:

- `time-late-not-worse`: the time-late model is never more than 5% worse than the instantaneous
  one at any point on the curve (it sees strictly more data).
- `*-beats-control`: each recurrent model beats its control (causal CNN, MLP) at 5 minutes after
  the zig and at the end of the window.
- `shuffled-labels-at-naive`: a model trained on shuffled labels scores within ±10% of naive.

All numbers below are from the committed experiment folder, generated at site build time. The
latest attempt is shown in full; earlier attempts stay on record and are listed at the end. A
metric shown as ∞ is a percentile that falls on a non-converged estimate (counted as +∞).

:::note G1 passed (panel round 3) with a caveat
The latest experiment, `20261012-g1-r2`, re-scores the time-late model after its one
[pre-registered continuation](https://github.com/debrief/Gitma/blob/main/experiments/20261011-g1-r2/review.md#user-decision-2026-10-12-after-round-1)
to early stopping (50 epochs, best 46). Its machine verdict is **inconclusive** because
`time-late-not-worse` fails; both ratio intervals lie wholly below 0.5 and the shuffled-label check
passes, so the agent review panel passed G1 under pre-registered rule 1 (SRD §5, amended
2026-10-12). Caveat: time-late is not shown better than instantaneous; it is measurably worse
(1.075 [1.046, 1.108] × instantaneous at zig + 300 s). Full record:
[`review.md`](https://github.com/debrief/Gitma/blob/main/experiments/20261012-g1-r2/review.md) and
the [write-up](/blog/2026/10/12/iteration-1). Attempt 1 (`20261011-g1-r2`, time-late stopped on
the wall-clock cap after 25 of 60 epochs) stays on record below.
:::
