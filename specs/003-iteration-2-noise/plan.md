# Implementation Plan: Iteration 2 — Is the Solution Useful Under Noise? (Gate G2)

**Branch**: `003-iteration-2-noise` | **Date**: 2026-10-11 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `/specs/003-iteration-2-noise/spec.md`

**Precondition**: G1 `pass`, decided by the agent review panel. Nothing in this plan is merged
before that, and the provenance/generator PR (A) must not merge while a G1 re-training run may still
be requested (it changes protected generator paths, so the G0 guard would refuse training).

## Summary

Close the dataset-lineage gap (generator commit and dirty flag in every dataset header, carried into
feature files, checked by `tma-train` against the G0 commit) and, if the user confirms, replace the
instantaneous zig with a rate-limited turn; re-run G0 with the panel. Generate a 10^5-scenario
dataset with σ ∈ {1°, 2°} and dropouts up to 10%, retrain the iteration-1 models on GitHub Actions
(phase A), diagnose on the validation split, and, if raw features stall, make one pre-declared change
(default: SRD §4 derived features — causal bearing rate and bearing-line intercept) and retrain
(phase B). Score the carried set once on test and judge G2 (σ = 1°, zig + 300 s, range < 20%,
course < 10°, speed < 1 kt) with bootstrap CIs, repeated iteration-1 checks and a classical
comparison on common rows; the panel decides. Publish results, blog and updated algorithm pages.

## Critical notes for review

- **The provenance change itself forces a G0 re-run.** `packages/data/src` is a guarded path
  (round-3 fix). Any PR touching it — even header-only — blocks training until G0 is re-run and the
  panel approves. Sequence: G1 final → PR A → G0 re-run + panel → any iteration-2 training.
- **Every dataset in CI is regenerated per job** and must be byte-identical; the plan pins expected
  digests so a silent generator change cannot slip between the G0 commit and the training commit.
- **G2 may be physically hard at zig + 300 s.** If classical at σ = 1° misses 20% median range error at
  that point (research R12), a model is unlikely to pass. The threshold is SRD text and is not moved;
  the achievability figure is shown to the user before training.
- **Phase B is conditional** on phase A stalling on validation (SRD §4 wording). This saves ≈ 6 h
  of CI but means a passing phase A leaves the derived features untested.
- **The shuffled-label test must be repeated for phase B**: derived features are a new input path,
  and an intercept computed with a frame error could leak geometry in unexpected ways.
- **Excluded fraction rises with the turn** (US6): the gate figure covers fewer scenarios; report it.

## Decisions (user, 2026-10-11)

The open questions were put to the user one at a time; all recommendations accepted.

1. **Rate-limited ownship turn**: in iteration 2 (US6 stays in scope), sharing the G0 re-run that
   the provenance change forces.
2. **Turn rate**: uniform 0.5–3°/s per scenario.
3. **G2 scope**: both variants must pass (mirrors G1).
4. **Phase B**: only if phase A stalls on validation (SRD §4 "if raw features stall").
5. **G2 fail after phase B**: one more iteration (2b) is allowed before stopping; phase B is the
   in-iteration round of SRD §7, not the SRD §5 "iterate once".
6. **Dropouts**: per-scenario uniform 0–10% (SRD §3), dropout becomes a slice.
7. **Inconclusive interval**: the panel may order one larger fresh-seed test set (e.g. 5× the test
   split); still inconclusive then counts as a fail.

8. **G2 speed point** (after the achievability check, research R12): range and course are judged
   at zig + 300 s, speed (< 1 kt) at zig + 600 s; SRD amended in its own PR.

## Decisions (user, 2026-10-13, after G1)

9. **Training budget**: 60 epochs, patience 3, no binding wall-clock cap; length bucketing and one
   tfjs thread for every model; up to three chained jobs per model (research R4, R17).
10. **Phase A**: G1 configurations unchanged; time-late leads (pre-zig loss share, gradient
    clipping) are not applied (research R0).
11. **Seeds**: one training seed per model, as G1; seed variance stated as a limit.
12. **G2 consistency failure** (pre-registered before any iteration-2 training): if every
    threshold check, both ratio checks and the shuffled-label check pass but
    `time-late-not-worse` fails, **G2 passes with the caveat stated**, as G1's rule 1. The machine
    verdict still reads `inconclusive` (G1's aggregation, kept); the panel applies this rule and
    records it in `decided_by`.
13. **Speed point stays zig + 600 s, with its coverage stated** (after the G0 re-run panel,
    2026-10-13): with the rate-limited turn, about 40% of scenarios end before zig + 600 s (all
    windows under ≈ 1000 s), so the speed criterion covers only the longer windows. The gate
    detail states the share reaching each point, and the G2 report states that a speed pass
    applies to windows of ≈ 1000 s or more (research R12).

Exit codes follow PR #21 (already implemented): **3 for any gate result other than pass**
(fail or inconclusive); the verdict file distinguishes them.
